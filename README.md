# MiniResourceDisplay

Simple personal resource-style health + power bar you can tweak.

Features:

- Just like the blizzard personal health and resource bar, but with some additions.
- Shows text value of your health and power.
- Can be moved anywhere on the screen.
- Can be resized and scaled.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
